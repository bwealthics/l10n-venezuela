Purchase and sale fiscal books (libros de compras y ventas) for
Venezuela:

- Uses the document date / invoice date and amounts in VES (an exchange
  rate is required).
- Aliquots 8 %, 16 % and 31 %, plus exempt and SDCF when the tax is
  tagged.
- Credit/debit notes keep the affected document number (negative
  amounts).
- VAT withholdings are shown in the voucher period, even if the invoice
  belongs to another month, when a VAT withholding module is installed.
- Posting the book locks the period: no new invoices of that type can be
  posted until an accounting manager reopens it.
- One open book per type, company and overlapping dates.
- Imports (Form 86) as document type 05 with expediente, when a customs
  module provides them.
- VAT write-offs of the period as type-04 adjustment lines, when a
  module provides them.
- Internal QWeb PDF (RLIVA Art. 75/76/78) and Excel export of the same
  columns. Not the official SENIAT XLSX template; no POS.

Configuration
=============

Tag taxes with their Venezuelan aliquot type (General, Reduced,
Additional, Exempt, SDCF). Keep the VES rate posted for the book period.
Posting a book locks that type (sales or purchases) for the period.

Usage
=====

1. *Accounting > Reporting > Generate Fiscal Book Wizard*, or create a
   book under *Purchase / Sale Fiscal Books*.
2. Choose type and period; generate / update to classify posted
   invoices.
3. *Confirm* and *Post / Lock Period* when the book is ready to file.
4. Print the QWeb report or use *Export Excel* (same columns as the
   PDF).
